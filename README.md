# 발명 탐구 실험실

홍북초 5학년 발명 탐구(빗물 건조망 덮개, 테이프 감개)를 위한 교수학습 웹앱입니다. 학생은 여섯 차시 탐구 노트를 태블릿에서 채우고, 3D 실험실에서 발명품 모형과 실험을 움직여 봅니다. 선생님은 학생 기록을 모아 보고 도장과 한마디를 남깁니다.

## 화면

- 학생: 탐구 지도, 차시 1~6(미션, 준비물, 3D 실험, 기록표, 계산, 생각, 퀴즈), 발명품 실험실, 탐구일지(인쇄), 낱말 사전, 면담 연습
- 선생님(`#/teacher`): 학생 현황과 QR, 학생별 기록과 예시 답, 도장·한마디, 차시 지도안, 전자칠판용 수업 화면, 비밀번호 바꾸기

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 배포 파일
```

## 구조

| 경로 | 내용 |
|---|---|
| `src/data/content.js` | 차시 내용, 낱말, 지도안. 문구를 고칠 때는 여기만 |
| `src/three/` | 3D 모형(빗물 덮개, 테이프 감개, 안내 캐릭터) |
| `src/labs/` | 차시별 3D 실험(도르래, 분무, 자석, 물 빼기, 각도, 빗면, 고무줄) |
| `src/pages/` | 화면 |
| `src/lib/store.js` | 기록 저장(기기에 먼저 저장, 0.9초 뒤 서버로) |
| `src/lib/api.js` | 수파베이스 RPC 호출 |

## 데이터

수파베이스 `maeumbit` 프로젝트의 `inv_students`, `inv_records`, `inv_feedback`, `inv_settings` 표에 저장합니다. 표는 앱에서 직접 읽을 수 없고, 이름과 비밀번호를 확인하는 `inv_` 함수로만 주고받습니다. 비밀번호는 bcrypt로 바꿔 저장합니다.
